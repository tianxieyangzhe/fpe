## 阅读顺序

1. 先读总体设计，理解目标、边界、分层和运行方式。
2. 再读接口与数据模型，明确 MCP 接口、结构体和协议。
3. 然后读工程与代码组织，确定目录、模式和代码风格。
4. 最后读开发计划与依赖清单，按阶段推进实现。
